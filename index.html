PlainVoice

Narration for AI-made videos. Unlimited, offline, with word timing your agent can use.

A text-to-speech app for macOS. People use the window; agents use MCP and the command line. No account, no per-character bill, no telemetry.

Download for macOS Install guide

macOS 14 or later, Apple silicon. Version 1.0 is not notarised yet; the install guide shows the one extra step on first open.

What it does

  • Unlimited, offline, on the CPU. Once the models are downloaded, voicing never touches the network.
  • Long jobs that survive anything. A whole book runs in the background and resumes after a quit, a crash or sleep. TXT, Markdown and EPUB in; chapters out.
  • Word timing on every line, as SRT, VTT and JSON, so video tools and agents can place captions and cuts.
  • Bad takes caught for you. An aligner flags skipped or invented words and re-rolls the line.
  • Agents are first-class. Every operation is an MCP tool and a CLI command. Jobs an agent starts show up live in the window, where you fix one line and re-voice only that line.
  • Pronunciation under your control: [word](respelling), [word](/phonemes/) and [pause:600ms] right in the script, plus dictionaries.
  • Vietnamese done properly: 23 voices from the North, Centre and South, with English words mixed in.
  • Exports as WAV (48 kHz mono 16-bit), FLAC, M4A and M4B audiobooks, each marked as AI-generated speech in its metadata.

For agents

Add PlainVoice to Claude Code as a plugin:

/plugin marketplace add plainvoice/plainvoice
/plugin install plainvoice

Or copy the setup for Claude Code or Codex from the app's Settings. Nine MCP tools cover voices, models, lint, synthesis, jobs, line fixes and pronunciations, and every one has a plainvoice CLI twin.
